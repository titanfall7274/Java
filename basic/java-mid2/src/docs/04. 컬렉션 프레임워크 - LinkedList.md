## 1. 노드와 연결

배열 리스트는 공간을 미리 잡아 두고(낭비), 앞에 넣으려면 전부 민다(O(n)). 연결 리스트는 **필요할 때마다 노드를 만들어 참조로 잇는다.**

```java
public class Node {
    Object item;  // 값
    Node next;    // 다음 노드 참조
}
Node first = new Node("A");
first.next = new Node("B");
first.next.next = new Node("C");   // [A -> B -> C]
```

```
first ─▶ [A | next] ─▶ [B | next] ─▶ [C | null]
```

순회는 `x = x.next`를 `null`이 될 때까지 반복한다 ([`NodeMain3`](../collection/link/NodeMain3.java): `printAll`, `getLastNode`, `getNode(index)`, `add`).

## 2. 직접 구현하는 연결 리스트 — 시작

[`MyLinkedListV1`](../collection/link/MyLinkedListV1.java) — `first` 노드와 `size`만 가진다.

- `get(index)` / `set(index)` : `index`번 `next`를 따라가야 한다 → **O(n)**
- `add(e)` (끝에 추가) : 마지막 노드를 찾아야 한다 → **O(n)**
- 배열처럼 용량 초과 개념이 없다.

## 3. 직접 구현하는 연결 리스트 — 추가와 삭제

[`MyLinkedListV2`](../collection/link/MyLinkedListV2.java)

```java
public void add(int index, Object e) {
    Node newNode = new Node(e);
    if (index == 0) {
        newNode.next = first;   // ① 새 노드가 기존 first를 가리키고
        first = newNode;        // ② first를 새 노드로 교체
    } else {
        Node prev = getNode(index - 1);
        newNode.next = prev.next;
        prev.next = newNode;
    }
    size++;
}
```

**참조만 바꾸면 끝**이라 밀기가 없다. 삭제도 `prev.next = removeNode.next`로 건너뛰게 하고, 지운 노드의 `item`, `next`를 `null`로 비운다.

| 연산 | 배열 리스트 | 연결 리스트 |
|------|:---:|:---:|
| 인덱스 조회 | **O(1)** | O(n) |
| 검색 | O(n) | O(n) |
| 앞에 추가·삭제 | O(n) | **O(1)** |
| 중간 추가·삭제 | O(n) (밀기) | O(n) (찾아가기) |
| 끝에 추가 | O(1) | O(n) → 자바 `LinkedList`는 O(1) |

💡 자바 `LinkedList`는 **이중 연결 리스트**다. `prev`, `next`를 모두 갖고 `first`, `last`를 둘 다 기억하므로 **양 끝 추가·삭제가 O(1)**, 인덱스 조회도 가까운 쪽 끝에서 출발한다.

## 4. 직접 구현하는 연결 리스트 — 제네릭 도입

[`MyLinkedListV3<E>`](../collection/link/MyLinkedListV3.java) — `Node`를 **`private static` 중첩 클래스 `Node<E>`** 로 안에 넣었다.

```java
private static class Node<E> {
    E item;
    Node<E> next;
}
```

- 배열 리스트와 달리 `item`이 곧 `E`라 꺼낼 때 캐스팅이 필요 없다.
- `Node`는 연결 리스트 내부에서만 쓰므로 밖에 노출하지 않는다 (캡슐화). `static`은 바깥 인스턴스 참조가 필요 없어서다.

## ✅ 핵심 요약

- 연결 리스트 = 노드(`item` + `next`)를 참조로 연결. 공간 낭비 없음.
- **앞쪽 추가·삭제 O(1)**, **인덱스 접근 O(n)**. 배열 리스트와 정확히 반대의 장단점.
- 자바 `LinkedList`는 이중 연결 + `last` 참조 → 양 끝 O(1).
