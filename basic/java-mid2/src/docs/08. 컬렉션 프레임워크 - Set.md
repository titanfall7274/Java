## 1. 자바가 제공하는 Set1 - HashSet, LinkedHashSet

```
Collection ─ Set ─┬─ HashSet ── LinkedHashSet
                  └─ (SortedSet) ─ TreeSet
```

- `HashSet` : 해시 테이블. 순서 **보장 안 함**. 추가·삭제·검색 평균 **O(1)**.
- `LinkedHashSet` : `HashSet` + 노드끼리 **연결 리스트로 입력 순서** 기억. 약간 느리고 메모리 더 씀.

## 2. 자바가 제공하는 Set2 - TreeSet

- **이진 탐색 트리**(자바는 균형을 맞추는 레드-블랙 트리)로 저장 → 값이 **정렬된 순서**로 유지된다.
- 추가·삭제·검색 **O(log n)**.
- 정렬 기준: 기본은 `Comparable`, 생성자에 `Comparator`를 넘길 수도 있다 ([10장 4절](10.%20컬렉션%20프레임워크%20-%20순회,%20정렬,%20전체%20정리.md#4-정렬---comparable-comparator)).

💡 이진 탐색 트리: 왼쪽 자식 < 부모 < 오른쪽 자식. 한 번 비교할 때마다 탐색 범위가 절반으로 줄어 O(log n). **중위 순회**(왼쪽→부모→오른쪽)하면 정렬 순서로 나온다.

## 3. 자바가 제공하는 Set3 - 예제

[`JavaSetMain`](../collection/set/javaset/JavaSetMain.java) — 같은 데이터 `C, A, B, 1, 2`를 세 구현체에 넣는다.

| 구현체 | 출력 순서 | 복잡도 |
|--------|----------|:---:|
| `HashSet` | 해시 순 (예측 불가) | O(1) |
| `LinkedHashSet` | 입력 순 `C A B 1 2` | O(1) |
| `TreeSet` | 정렬 순 `1 2 A B C` | O(log n) |

`run(Set<String> set)`처럼 **`Set` 인터페이스로 받으면** 구현체만 바꿔 끼워 비교할 수 있다.

## 4. 자바가 제공하는 Set4 - 최적화

- 자바 `HashSet`은 데이터가 **용량의 75%(load factor)** 를 넘으면 배열을 **2배**로 늘리고 전부 재배치(rehashing)한다 → 충돌을 낮게 유지.
- 해시 인덱스는 `%` 대신 비트 연산 등으로 더 빠르게, 해시 코드도 한 번 더 섞어서 고르게 퍼뜨린다.
- 한 버킷에 너무 많이 몰리면 리스트 대신 트리로 바꿔 최악을 O(log n)으로 줄인다.

## 5. 문제와 풀이

| 파일 | 핵심 |
|------|------|
| [`UniqueNamesTest1`](../collection/set/test/UniqueNamesTest1.java) | 중복 제거 — 순서 무관 `HashSet`, 입력 순 `LinkedHashSet`, 정렬 `TreeSet` |
| [`RectangleTest`](../collection/set/test/RectangleTest.java) | `Rectangle`에 `equals`/`hashCode`(`Objects.hash(width, height)`) → `(20,20)` 중복 제거 |
| [`SetOperationsTest`](../collection/set/test/SetOperationsTest.java) | 집합 연산 |

```java
// SetOperationsTest
union.addAll(set1); union.addAll(set2);                             // 합집합
HashSet<Integer> intersection = new HashSet<>(set1);
intersection.retainAll(set2);                                       // 교집합
HashSet<Integer> difference = new HashSet<>(set1);
difference.removeAll(set2);                                         // 차집합
```

💡 `new HashSet<>(List.of(...))`처럼 **생성자에 컬렉션을 넘기면 한 번에 복사**된다.

## ✅ 핵심 요약

| 필요 | 선택 |
|------|------|
| 그냥 중복 제거 (가장 빠름) | `HashSet` |
| 입력 순서 유지 | `LinkedHashSet` |
| 정렬 순서 / 범위 검색 | `TreeSet` (O(log n)) |

- 해시 계열에 넣는 객체는 `equals`/`hashCode`, `TreeSet`에 넣는 객체는 `Comparable` 또는 `Comparator`.
