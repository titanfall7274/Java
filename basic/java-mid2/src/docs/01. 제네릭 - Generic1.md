## 1. 제네릭이 필요한 이유

타입마다 상자를 따로 만들면 **타입 안전성은 있지만 재사용이 안 된다.**

```java
// BoxMain1 — IntegerBox, StringBox ...
integerBox.setValue(10);
// integerBox.setValue("20"); // compile Error가 발생하여 타입 안전성이 높다.
// 그러나 이런 경우 타입별로 xxxBox라는 형식으로 새로운 클래스를 계속 만들어야 한다는 단점이 존재한다.
```

## 2. 다형성을 통한 중복 해결 시도

`Object`로 받으면 재사용은 되지만 **꺼낼 때 캐스팅이 필요하고, 잘못된 값이 들어와도 컴파일러가 못 막는다.**

```java
// BoxMain2
Integer integer = (Integer) integerBox.get(); // Object > Integer 캐스팅
integerBox.set("문자100");                    // 컴파일 에러가 나지 않게되고
Integer result = (Integer) integerBox.get();  // ClassCastException이 발생합니다.
```

| 방식 | 재사용 | 타입 안전성 |
|------|:---:|:---:|
| `IntegerBox`, `StringBox` … | ❌ | ✅ |
| `ObjectBox` (다형성) | ✅ | ❌ |
| `GenericBox<T>` (제네릭) | ✅ | ✅ |

## 3. 제네릭 적용

```java
public class GenericBox<T> {
    private T value;
    public void set(T value) { this.value = value; }
    public T get() { return value; }
}

GenericBox<Integer> integerBox = new GenericBox<Integer>();
Integer integer = integerBox.get();                      // 캐스팅 불필요
GenericBox<Integer> integerBox2 = new GenericBox<>();    // 타입 추론 — 다이아몬드 <>
```

- **클래스를 정의할 때는 타입을 정하지 않고, 생성하는 시점에 정한다.** `T`는 그 자리를 비워 둔 변수다.
- 타입 추론: 왼쪽 선언에 `<Integer>`가 있으니 오른쪽 `new GenericBox<>()`는 생략해도 컴파일러가 채운다.

## 4. 제네릭 용어와 관례

| 용어 | 뜻 | 예 |
|------|----|----|
| 제네릭 타입 | 타입 매개변수를 가진 클래스·인터페이스 | `GenericBox<T>` |
| 타입 매개변수 | 선언부의 비어 있는 자리 | `T` |
| 타입 인자 | 사용할 때 넣는 실제 타입 | `Integer` |

- 타입 인자로 **기본형은 못 쓴다** → `int` 대신 `Integer` (래퍼 클래스).
- 이름 관례: `E` Element, `K` Key, `V` Value, `N` Number, `T` Type, `S·U·V` 2·3·4번째.
- 여러 개도 가능: `Pair<K, V>` ([`Pair`](../generic/test/ex2/Pair.java)).

⚠️ **로 타입(raw type)** — `new GenericBox()`처럼 `<>`를 빼면 `Object`로 동작한다. 하위 호환용일 뿐 쓰지 않는다.

```java
// RawTypeMain
GenericBox integerBox = new GenericBox();          // raw type >> Object를 사용된다고 이해하면 된다.
// GenericBox<Object> integerBox = new GenericBox<>(); // 권장
```

## 5. 제네릭 활용 예제

`Box<Animal>`에는 `Animal`의 자식(`Dog`, `Cat`)도 담긴다. **타입 인자로 정한 타입과 그 하위 타입이 들어갈 수 있다** — 일반 다형성 규칙 그대로.

```java
// AnimalMain2
Box<Animal> animalBox = new Box<>();
animalBox.set(dog);
animalBox.set(cat);
Animal findAnimal = animalBox.get(); // 꺼낼 땐 Animal
```

## ✅ 핵심 요약

- 제네릭 = **재사용 + 타입 안전성**. `Object` 다형성은 재사용만, 타입별 클래스는 안전성만 준다.
- 타입은 **선언 시점이 아니라 생성 시점**에 정해진다.
- 타입 인자는 참조형만. `new X<>()` 다이아몬드로 추론. 로 타입은 쓰지 않는다.
